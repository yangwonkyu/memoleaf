# Session Results — 시작 난이도와 플레이 기록 검증

MemoLeaf에서 여러 미니게임을 웹에 연결하며 다룬 판단을 보여주는 독립 C# 예제입니다. 실무 경험을 바탕으로 Codex와 함께 새로 작성했으며, 회사 원본 코드·데이터 형식·서버 주소는 포함하지 않습니다.

- **시작 난이도:** 웹에서 6단계를 요청했지만 게임이 2·4·8단계만 지원하면 4단계를 적용합니다. 요청이 모든 지원 단계보다 낮으면 최저 지원 단계로 시작합니다.
- **공통 기록과 게임별 기록:** 라운드와 문제 번호, 시간, 판정은 공통으로 두고 게임마다 다른 값은 제네릭 `Details`에 담습니다. 예제는 가상의 색 고르기 게임을 사용합니다.
- **결과 검증:** 중복되거나 역순인 문제 번호와 음수 시간을 거절합니다. 무응답 시간 초과는 첫 반응시간이 없는 기록으로 남기며 오답으로 바꾸지 않습니다.
- **전송과 분리:** 이 예제의 책임은 JSON 생성까지입니다. 네트워크나 Unity 씬에 연결하지 않아 입력과 결과를 독립적으로 확인할 수 있습니다.

[핵심 C# 코드](SessionResults.cs) · [검증 코드](Verify.ps1) · [실무에서 데이터를 설계한 사례](../../docs/trial-data-design.md)

## 실행

PowerShell 7.6에서 저장소 루트 기준으로 실행합니다. Unity 프로젝트나 외부 패키지는 필요하지 않습니다.

```powershell
pwsh -NoProfile -File samples/session-results/Verify.ps1
```

성공하면 검증 결과와 예제 JSON이 출력됩니다.
