# Portfolio Evidence Policy

## Purpose

이 저장소는 Unity 클라이언트 개발 역량을 공개 가능한 방식으로 설명하기 위한 포트폴리오 저장소입니다.

회사 프로젝트의 소스 코드나 내부 리소스를 공개하지 않고도, 구현 흐름과 개발 판단을 설명할 수 있도록 구성합니다.

## Do Not Upload

- 회사 프로젝트 원본 코드
- 회사 내부 리소스
- 비공개 이미지, 사운드, 이펙트, 애니메이션
- 내부 데이터 테이블
- 서버 API 명세
- 빌드 파일
- 회사명이 드러나는 내부 툴 화면
- 권한이 불명확한 캡처 이미지

## Safe To Upload If Cleared

- 개인 프로젝트 코드
- 직접 만든 샘플 코드
- 회사 코드가 아닌 형태로 재작성한 예제
- 공개 가능한 GIF 또는 스크린샷
- 기능 흐름도
- 구현 설명
- 문제 해결 과정

## How To Explain Company Work Without Code

회사 코드를 공개할 수 없는 작업은 다음 방식으로 설명합니다.

1. 맡은 범위
2. 문제 상황
3. 구현 흐름
4. 사용한 Unity/C# 기능
5. 예외 상황 처리
6. 결과 화면 또는 공개 가능한 GIF

## Example Wording

> 회사 프로젝트의 원본 코드는 공개할 수 없어 제외했습니다. 대신 동일한 구현 의도를 설명하기 위해 기능 흐름도, 공개 가능한 결과 GIF, 그리고 개인적으로 재작성한 샘플 구조를 함께 정리했습니다.

## Review Checklist

- 회사 코드가 포함되어 있지 않은가?
- 회사 내부 리소스가 포함되어 있지 않은가?
- GIF/이미지 공개 권한이 명확한가?
- 채용자가 30초 안에 내가 맡은 역할을 이해할 수 있는가?
- 각 GIF 옆에 개발자 관점의 설명이 붙어 있는가?
